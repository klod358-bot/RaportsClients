# АВТОКИНО — сайт-визитка AI-видео с автомобилем клиента

**Сайт:** https://klod358-bot.github.io/RaportsClients/autokino/

Клиент смотрит примеры, читает, что нужно подготовить, оплачивает переводом и нажимает «Написать в WhatsApp». Открывается чат с номером из настроек и готовым сообщением, в которое остаётся вписать имя и данные машины, а затем прикрепить фото и чек.

Что клиент присылает в WhatsApp:
- фото автомобиля с четырёх сторон — спереди, сзади, слева, справа (на сайте есть подсказки по каждому ракурсу);
- своё фото — в полный рост или по пояс, с хорошо видимым лицом;
- имя, марку, модель, год и цвет машины;
- пожелания к сюжету (необязательно);
- чек об оплате.

Сервер и база не нужны — сайт полностью статический и работает на GitHub Pages.

## Как поменять цену, номер, текст сообщения

Всё в одном файле — [`config.js`](config.js). Редактируется прямо на GitHub: карандаш → Commit changes. Сайт обновится через 1–2 минуты.

| Что | Где в `config.js` |
| --- | --- |
| Цена одного ролика | `price: 10000` |
| Номер для перевода | `payment.phone` |
| Имя получателя (под номером) | `payment.recipient` — пока пусто, строка скрыта |
| Банк (например, Kaspi) | `payment.bank` — пока пусто, строка скрыта |
| Номер WhatsApp для заказов | `contacts.whatsapp` |
| Instagram | `contacts.instagram` — ник без @; пока пусто, кнопка скрыта |
| Готовое сообщение в WhatsApp | `whatsappText` |

Если клиент нажмёт «Хочу такое же» на одном из роликов, в сообщение добавится строка «Хочу как в примере «Название»».

## Как добавить или убрать видео в галерее

1. Загрузите ролик `.mp4` в папку [`videos/`](videos) (Add file → Upload files). Лучше вертикальный 9:16 и до 20 МБ.
2. В `config.js` в список `videos` добавьте строку:

```js
{ src: 'videos/moy-rolik.mp4', title: 'Название', note: 'Подпись под названием', duration: '0:30' },
```

Обложку (`poster`) можно не указывать — возьмётся первый кадр. Если есть картинка-обложка, загрузите её туда же и добавьте `poster: 'videos/moy-rolik.jpg'`. Порядок строк = порядок на сайте. Чтобы убрать ролик, удалите его строку.

Горизонтальные ролики в карточках показываются по центру кадра, а при открытии — целиком. Какую часть кадра показывать в карточке, задаёт `focus` (`'30%'` — левее, `'70%'` — правее).

## Файлы

```
autokino/
├── index.html      сайт
├── config.js       настройки: цена, номера, текст сообщения, видео
├── videos/         ролики-примеры, обложки и фоновое видео главного экрана
└── assets/         стили, скрипты, шрифты (Sofia Sans, лицензия OFL), картинки
```

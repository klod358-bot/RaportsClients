# АВТОКИНО — сайт заказа AI-видео с автомобилем клиента

- **Сайт:** https://klod358-bot.github.io/RaportsClients/autokino/
- **Админка:** https://klod358-bot.github.io/RaportsClients/autokino/admin.html

Клиент смотрит примеры, заполняет заявку, загружает фото машины с четырёх сторон (спереди, сзади, слева, справа), свои фото и чек о переводе. Заявка получает номер (AV-1001, AV-1002…), файлы сохраняются в Google Drive, строка — в Google Таблицу, а в Telegram приходит уведомление со всеми фото и чеком. В админке можно смотреть заявки и менять статус.

Сайт работает сразу после публикации. **Принимать заявки он начнёт после подключения сервера** — это 4 шага ниже, около 10 минут. До подключения кнопка отправки показывает клиенту сообщение и предлагает написать в WhatsApp.

## Подключение сервера (один раз)

Сервер — это бесплатный скрипт Google Apps Script в вашем Google-аккаунте. Он хранит заявки на вашем Google Диске и отправляет уведомления в Telegram.

### 1. Telegram-бот для уведомлений

1. В Telegram откройте **@BotFather** → `/newbot` → придумайте имя → скопируйте **токен** вида `123456789:AA…`.
2. Откройте своего нового бота и нажмите **Start** (или добавьте бота в рабочую группу и напишите там любое сообщение — тогда заявки будут приходить в группу).

### 2. Скрипт в Google

1. Откройте https://script.google.com → **Новый проект**. Назовите его, например, «АВТОКИНО сервер».
2. Удалите всё в файле `Code.gs` и вставьте содержимое файла [`backend/Code.gs`](backend/Code.gs) из этой папки.
3. В начале файла, в блоке `CONFIG`, заполните:
   - `ADMIN_PASSWORD` — пароль для входа в админку (придумайте надёжный);
   - `TELEGRAM_BOT_TOKEN` — токен из шага 1.
4. Сохраните (значок дискеты). Сверху выберите функцию **findTelegramChatId** → **Выполнить**. Google попросит разрешения: **Предоставить доступ** → выберите аккаунт → «Приложение не проверено» → **Дополнительные настройки** → **Перейти на страницу…** → **Разрешить**. Это ваш собственный скрипт, предупреждение стандартное.
5. Внизу в журнале появится строка `ID чата: 123456789`. Вставьте это число в `TELEGRAM_CHAT_ID` и сохраните.
6. Выберите функцию **setup** → **Выполнить**. Скрипт создаст на Google Диске папку «АВТОКИНО — заказы» с таблицей заказов внутри и пришлёт в Telegram сообщение «уведомления о заказах подключены».

### 3. Публикация скрипта

1. Справа сверху **Начать развертывание** (Deploy) → **Новое развертывание**.
2. Шестерёнка «Выберите тип» → **Веб-приложение**.
3. «Запуск от имени»: **Я**. «У кого есть доступ»: **Все**.
4. **Начать развертывание** → скопируйте **URL веб-приложения** (заканчивается на `/exec`).

### 4. Адрес сервера на сайте

Откройте на GitHub файл [`config.js`](config.js) → карандаш (Edit) → вставьте ссылку в `apiUrl`:

```js
apiUrl: 'https://script.google.com/macros/s/AKfy…/exec',
```

**Commit changes**. Через 1–2 минуты отправьте с сайта тестовую заявку: она должна прийти в Telegram и появиться в админке.

> **Если потом меняете `Code.gs`** (пароль, токен и т. п.): «Начать развертывание» → **Управление развертываниями** → карандаш → Версия: **Новая версия** → «Начать развертывание». Ссылка `/exec` останется прежней.

## Как поменять цену, номер для оплаты, контакты

Всё в одном файле — [`config.js`](config.js). Редактируется прямо на GitHub (карандаш → Commit changes):

| Что | Где в `config.js` |
| --- | --- |
| Цена одного ролика | `price: 10000` |
| Номер для перевода | `payment.phone` |
| Имя получателя (показывается под номером) | `payment.recipient` — пока пусто, строка скрыта |
| Банк (например, Kaspi) | `payment.bank` — пока пусто, строка скрыта |
| WhatsApp в шапке и подвале | `contacts.whatsapp` |
| Instagram | `contacts.instagram` — ник без @; пока пусто, иконка скрыта |
| Сколько роликов можно заказать за раз | `maxVideosPerOrder` |

## Как добавить или убрать видео в галерее

1. Загрузите ролик `.mp4` в папку [`videos/`](videos) (Add file → Upload files). Лучше вертикальный 9:16 и до 20 МБ.
2. В `config.js` в список `videos` добавьте строку:

```js
{ src: 'videos/moy-rolik.mp4', title: 'Название', note: 'Подпись под названием', duration: '0:30' },
```

Обложку (`poster`) можно не указывать — возьмётся первый кадр. Если есть картинка-обложка, загрузите её туда же и добавьте `poster: 'videos/moy-rolik.jpg'`. Порядок строк = порядок на сайте. Чтобы убрать ролик, удалите его строку.

Горизонтальные ролики в карточках показываются по центру кадра, а при открытии — целиком. Какую часть кадра показывать в карточке, задаёт `focus` (`'30%'` — левее, `'70%'` — правее).

## Админка

`admin.html`, вход по паролю из `CONFIG.ADMIN_PASSWORD`. Что в ней есть:

- список заказов с поиском по номеру, имени, телефону и машине, фильтр по статусу;
- карточка заказа: данные клиента и машины, пожелания, все фото и чек (нажмите, чтобы открыть в полном размере и скачать);
- кнопка «Написать в WhatsApp» с готовым приветствием и номером заказа;
- статусы: Новый → Ожидает проверки оплаты → Оплачен → В работе → Готов → Отправлен клиенту;
- заметка к заказу для себя;
- ссылки на таблицу и папку на Google Диске.

Статус можно менять и прямо в таблице: в колонке «Статус» выпадающий список.

После 10 неверных паролей вход блокируется на 10 минут.

## Где хранятся заявки

- **Google Таблица** «АВТОКИНО — заказы» — одна строка на заказ.
- **Google Диск**, папка «АВТОКИНО — заказы» — внутри папка на каждый заказ (`AV-1001 — Имя — Марка Модель`) с фото и чеком. Файлы доступны только вам.
- **Telegram** — сообщение с данными, альбом фото и чек.

Фото сжимаются прямо в телефоне клиента (до 1920 px по длинной стороне), поэтому заявка весит 2–5 МБ и отправляется быстро. Бесплатных 15 ГБ Google Диска хватит примерно на 3000 заказов.

## Проверки в форме

Обязательно: имя, телефон, марка, модель, год, цвет, 4 фото машины, хотя бы одно фото клиента (до 5), чек (JPG, PNG или PDF, до 10 МБ) и согласие на обработку данных. Перед отправкой клиент видит сводку заказа. Если интернет пропал, данные не теряются — можно нажать «Отправить ещё раз», дубля заявки не будет. Текстовые поля сохраняются в браузере, если клиент случайно закрыл страницу.

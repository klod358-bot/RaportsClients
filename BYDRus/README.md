# BYD Русификатор

Приложение для головных устройств BYD (DiLink) на китайской прошивке. Одна кнопка:

1. **Определяет автомобиль** — читает системные свойства прошивки и находит модель
   (Tang, Han, Song, Qin, Yuan/Atto 3, Seal, Dolphin, Seagull, Destroyer, Frigate, Denza).
2. **Выдаёт себе права** — подключается к ADB самого автомобиля (`127.0.0.1:5555`),
   если на нём включена отладка по сети. Компьютер тогда не нужен.
3. **Включает перевод экрана** — служба читает китайские надписи в любых приложениях
   и рисует поверх них русский текст по словарю. Root не нужен.
4. **Переключает язык системы** на «русский, запасной — английский»: там, где у BYD
   нет русского, появится английский вместо китайского.

Кнопка «Вернуть как было» возвращает исходный язык и выключает перевод.

## Как получить APK

**Без установки программ (GitHub Actions, ~5 минут)**

1. Создайте на github.com новый приватный репозиторий.
2. Загрузите в него содержимое этой папки целиком (включая скрытую папку `.github`).
3. Вкладка **Actions** → сборка **Build APK** запустится сама.
4. Когда она позеленеет, откройте её и скачайте артефакт **BYDRus-apk** — внутри `BYDRus.apk`.

**Через Android Studio**

Откройте папку проекта, дождитесь синхронизации, затем *Build → Build APK(s)*.
Или в терминале: `gradlew assembleRelease` → `app/build/outputs/apk/release/app-release.apk`.

## Установка и первый запуск

1. Установите `BYDRus.apk` на головное устройство (с флешки через файловый менеджер
   или `adb install BYDRus.apk`).
2. Запустите и нажмите **«Русифицировать автоматически»**.
3. Если появится запрос «Разрешить отладку?» — отметьте «Всегда разрешать» и подтвердите.

Если приложение пишет, что ADB недоступен, один раз выдайте права с компьютера:

```
adb shell pm grant com.bydrus.app android.permission.WRITE_SECURE_SETTINGS
adb shell pm grant com.bydrus.app android.permission.CHANGE_CONFIGURATION
adb shell appops set com.bydrus.app WRITE_SETTINGS allow
```

и нажмите кнопку ещё раз. Совсем без ADB работает только перевод экрана, и то
если в прошивке есть экран «Специальные возможности», где службу можно включить вручную.

## Словарь

Встроенный словарь: `app/src/main/assets/dict/common.txt` (общий) и `tang.txt`
(добавки для Tang). Формат строки — `китайский=русский`.

На самом автомобиле, в папке `Android/data/com.bydrus.app/files/`:

- `untranslated.txt` — всё, что приложение увидело на экране и не смогло перевести;
- `user_dict.txt` — ваш словарь, перекрывает встроенный (после правки нажмите
  в приложении «Выбрать модель» → ту же модель, чтобы перечитать);
- `diagnostics.txt` — появляется по кнопке «Сохранить диагностику»: что прошивка
  сообщает о себе. Нужен, если модель определилась неверно.

Словарь составлен по типовой терминологии интерфейса BYD, а не снят с конкретной
прошивки, поэтому первым делом стоит собрать `untranslated.txt` с вашей машины
и дополнить словарь.

## Чего приложение не может

- Перевести приборную панель — она работает на отдельном блоке.
- Перевести текст, нарисованный картинкой, и голосовые подсказки.
- Заменить надписи «по-настоящему»: перевод рисуется поверх, с задержкой в доли
  секунды после смены экрана; плашки могут не совпадать с фоном по цвету.
- Работать на прошивках, где BYD закрыл установку сторонних APK и ADB.

## Устройство проекта

| Файл | Назначение |
|---|---|
| `MainActivity` | экран, автонастройка по шагам |
| `CarDetector` | определение модели и диагностика |
| `AdbClient` | встроенный ADB-клиент (выдача прав самому себе) |
| `LocaleSwitcher` | смена языка системы |
| `TranslatorService`, `OverlayView` | перевод экрана и отрисовка подписей |
| `Dictionary` | словарь, пословная сборка, сбор непереведённого |
| `BootReceiver` | возвращает перевод после перезагрузки |

Только Java, без сторонних библиотек. minSdk 24 (Android 7), targetSdk 28.
